Data Sourcing

Where does it come from?

All displayed statistics are sourced from combos that appear in the WBO top 3 forum page. Images are mainly taken from the Beyblade Wiki, and are not my own.

How I source data:

Data is collected using a worker script that I made. I run it manually, so if data is ever delayed it's because I haven't had time to do that yet. Unlike many past Beyblade meta trackers, this script does not use an AI agent, and therefore does not feed any information into an AI trainer.

The load on WBO servers is minimal, since I'm really just logging one once or twice a week. However, the downside is that this script doesn't catch everything. If a post doesn't follow the suggested WBO formatting, certain parts may show up multiple times. As one person who is in college, I don't have time to filter every type of possible input while also updating to support new parts/beys every month.
